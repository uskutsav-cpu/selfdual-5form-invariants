## 4. Canonicalisation audit (discharges PO-01)

The historical Weisfeiler–Leman concern does **not** apply at this commit:

- `_canonical_wl` no longer exists in `src/sdinv/graphs.py`;
- `canonical()` uses pynauty's exact certificate when available, the exact n!
  form for n ≤ 6 otherwise, and **raises** above 6 vertices with neither —
  it fails loudly rather than silently undercounting;
- pynauty is importable at runtime and pinned in the lockfile;
- order 8 is generated by nauty's `geng | multig`, so labelled duplicates never
  arise.

## 5. Generator enumeration and holdouts (discharges PO-02 partially, PO-06)

**Generator completeness.** The 18 trace generators are exactly the multisets of
`Tr(τ^k)` whose leading field degrees sum to ≤ 12. Verified: 18 expected = 18
present, none missing, none extra, and leading degrees are additive across
products for every generator (`[1,1] → 8 = 4+4`, etc.). This is what makes the
degree-6 argument behind the K6 result *exhaustive* rather than sampled — only
`tr_tau` (4), `tr_tau2` (4), `tr_tau3` (6) can reach degree 6, and all three
produce rows.

**Two independent holdouts.** Two assemblies over the six available interacting
certificates, each excluding a different prime:

| fit primes | holdout | result |
|---|---|---|
| 32749, 32719, 32693, 32771, 32717 | 32713 | passed |
| 32749, 32719, 32693, 32771, 32713 | 32717 | passed |

Both agree on new-forcing dimensions `{4:1, 6:1, 8:3, 10:5, 12:21}` and produce
**192/192 identical** reconstructed coordinate vectors.

## 6. Operational hazard recorded

The canonical working tree lives under `~/Documents/Codex/...`, which is
**iCloud-synced**. During the preceding session this caused file writes to
appear with no local process (`ps` showed nothing, `lsof` showed no handles),
and a naive copy produced a torn snapshot in which a stale `.py` was paired
with newer `.pyc`, causing pytest to execute stale bytecode and report a
spurious failure.

Consequences adopted here, consistent with the resource policy:

- reproduction is done in a non-synced directory;
- copies exclude `__pycache__` and `.pytest_cache`;
- activity is judged by file mtimes over a ≥60 s window, never by `ps`.
