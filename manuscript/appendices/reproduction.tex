\paragraph{Full reproduction.} The comparison and Jacobian certificates are
regenerated by the scripts in \texttt{spinor\_trace\_bridge/scripts/}. Each
writes its output incrementally and skips work already recorded, so a long run
can be interrupted and resumed.
