# Dependencies for BUILDING THE MANUSCRIPT only.
#
# Kept separate from the top-level requirements.txt on purpose. That file pins
# the environment the scientific results were certified in, and adding a
# plotting library to it would misrepresent what the certified runs needed.
# Nothing here participates in any computation whose result is quoted.
#
#     python3 -m pip install -r manuscript/requirements-docs.txt
#
# Also required, but not installable via pip:
#   * a TeX engine -- Tectonic (tested: 0.17.0) or a TeX Live pdflatex
#   * pandoc, only for rendering the mentor-package markdown documents to PDF
#     (tested: 3.10.1)

# Requires Python >= 3.11 (matplotlib 3.11.1 does not build for older). The
# project as a whole requires Python >= 3.10 for PEP 604 union annotations; the
# certified environment was Python 3.13.
#
# Pinned exactly, not floored. Figure output is byte-reproducible for a FIXED
# matplotlib version, but not across versions: 3.9.4 and 3.11.1 emit different
# PDF bytes for identical input. A clean clone resolving a different version
# therefore produces figures that are visually identical and byte-different,
# which breaks archive hash comparison. This was found by a clean-clone run, not
# assumed.
matplotlib==3.11.1
