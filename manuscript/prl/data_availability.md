# Data availability

All code, certificates and manuscript sources are in the public repository
recorded in the code availability statement. Every number in the Letter is
generated from a machine-readable certificate by a versioned script; none is
transcribed.

The spinor enumeration archive analysed in the cross-validation is third-party
and is **not** redistributed. The repository ships a manifest of per-file hashes
and adapter instructions so a reader holding their own copy can reproduce the
archive-dependent results. All other results reproduce without it.
